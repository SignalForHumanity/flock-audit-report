# Review

- [fixed] harm: free-text reasons (old-style reasons, which become the "category", and flagged reasons and text prompts) were shown verbatim. They often contain plate numbers ("stolen veh ABC1234"), which broke the "never shows a plate" promise in a report meant to be pasted into articles (src/analyze.rs:274, src/analyze.rs:306) -> new `mask_plates` (src/classify.rs:395) replaces plate-like tokens with `[plate]` before reasons are counted and shown. Regression test `plates_in_free_text_reasons_are_masked`, plus unit test `plate_masking`.
- [fixed] honesty: README and page said names and plates are never shown, but reason text can still name victims or suspects -> README limitations and page footer now say reasons are shown as written (plate-like words masked) and should be read before publishing.
- [fixed] correctness: a state name inside a county, township or city name was read as the state, so "Washington County Sheriff's Office", "Delaware County SO", "Ohio County SO", "Washington Township PD", "Kansas City PD" and "Michigan City PD" were all put in the wrong state, which distorts the main in-state/out-of-state numbers (src/classify.rs:201) -> a state name followed by county/co/township/twp/parish/city does not count, except cities that are in their namesake state (Oklahoma City, Iowa City, Texas City, Florida City, Delaware City). Two-letter codes still take priority ("Washington County AR SO" -> AR). Regression cases added to `jurisdictions`. README limitation updated.
- [fixed] correctness: the delimiter was detected from the first chunk only, even when the header line had not finished arriving. A semicolon or tab file pushed in small chunks was parsed as comma-separated and skipped as "not a Flock audit" (src/csv.rs:80) -> bytes are held until the whole header line has arrived (or until `finish`). Regression test `semicolon_file_in_small_chunks`.
- [fixed] correctness: dates with two-digit years, which Excel writes when it re-saves a CSV ("4/24/26 5:34"), were not parsed, so every row went into "(no date)" (src/classify.rs:462) -> two-digit years are read as 20YY. Regression case in `dates`; README lists the format.
- [fixed] honesty: README said drug slang "ice" is not counted as ICE. That is only true in lowercase; a reason typed all in capitals ("DRUGS - ICE") is flagged as immigration -> README limitation added. Not changed in code: telling the two apart in all-caps text needs context the tool does not have.
- [fixed] accessibility: the `<progress>` bar had no accessible name (web/index.html:34) -> added `aria-label`.
- [unfixed] correctness: reasons of 3 characters or fewer, such as "DUI" or "DWI", count as vague. This rule is documented in README and comes from the published methodology, so I left it as designed.
- [unfixed] correctness: operators are keyed by name only, so two officers with the same name at different agencies are merged. This rarely changes the counts, and keying by name plus agency would change the documented "first seen" agency column.

Summary: the tool does what PROBLEM.md promises, end to end. The page streams multiple CSVs in chunks, removes duplicate search IDs, classifies agencies, reasons, keywords and scope, and outputs HTML, text and CSV. On the real UNC Pembroke excerpt the numbers match the independent count, so the verdict stays `build`. The most important problem was privacy: free-text reasons were shown verbatim, so plates could appear in a report the README said would never contain one. Plate-like tokens are now masked, and the docs warn that reasons can still name people. The main accountability number was also wrong for many real agencies, because county, township and city names containing a state name ("Washington County", "Kansas City") were counted as in-state or out-of-state. Two smaller parsing bugs are fixed: delimiter detection on small chunks, and Excel's two-digit-year dates. Every correctness fix has a regression test that failed before the fix. fmt, clippy, tests, audit and the web build all pass. The web page makes no external requests and never uploads files.
